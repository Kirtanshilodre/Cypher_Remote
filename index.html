// SETUP GUIDE

Get Connected in 3 Steps

01

SAME NETWORK

Connect PC and phone to same WiFi or hotspot.

02

RUN PC APP

Windows: Open CypherPC.exe → tray icon shows IP → allow Firewall.

Mac: Open CypherMAC.app → allow Accessibility → IP shown in window.

IP: 192.168.x.x  |  PORT: 3000
03

CONNECT FROM PHONE

Open Cypher Remote → scan QR code OR enter IP → tap Connect PC Socket. Done. ✅

// MAC NOTE

First run — macOS will ask for Accessibility permission. Go to System Settings → Privacy & Security → Accessibility and enable CypherMAC.
