// SETUP GUIDE

Get Connected in 3 Steps

Takes less than 2 minutes.

01

CONNECT TO SAME NETWORK

Your PC and phone must be on the same WiFi or hotspot. Turn on your phone's hotspot and connect your PC to it — or connect both to your home WiFi.

02

RUN CYPHER PC

Open CypherPC.exe on your Windows PC. A window will appear showing your IP address and port. The server starts automatically.

IP: 192.168.x.x  |  PORT: 3000
03

CONNECT FROM PHONE

Open the Cypher Remote app on your Android phone. Enter the IP address shown in CypherPC, set port to 3000, and tap Connect. Done.

// MAC SETUP

First time on Mac — open Terminal and run this once:

pip3 install pyautogui , python3 cypher_mac_app.py

Then open cypher_mac_app.py — or double click the .app if you built it. Allow accessibility permissions when prompted by macOS.

// NOTE

Allow CypherPC.exe through Windows Firewall when prompted — this is required for the connection to work. If connection fails, check that both devices are on the same network.
